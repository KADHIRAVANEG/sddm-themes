Get it running.

Three commands is all it takes. The installer handles everything — dependency check, existing theme backup, Qt5/Qt6 detection, and sddm.conf update.

01
Clone the repo
git clone https://github.com/KADHIRAVANEG/sddm-themes
02
Run the installer as root
cd sddm-themes
sudo ./install.sh
03
Pick your theme & reboot

Enter a theme number at the prompt. The installer checks dependencies and prepares the theme before activating it for your next login.

TIP Preview without rebooting: sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/<id>
